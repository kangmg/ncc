# Pure SVG header

Audience: Computational chemists sharing useful small results.
One-sentence value: Small findings deserve to be shared.
Primary proof: The journal already publishes versioned computational notes and manuscript examples.
First successful action: Read a note or open a submission Issue.
Visual theme: A reaction path becomes a shared research note.

Implementation: Pure SVG. All lettering uses editable text; the illustration uses paths, circles, and ellipses. No embedded raster images, remote resources, scripts, or web fonts.
Palette: Website masthead #1c3558 / #28517d / #3f739d; white #ffffff; supporting type #d6e2ef; gold #d7ae62; mesh #b4cbee.
Typography: Georgia / Times New Roman / serif, 80-unit bold title; Helvetica / Arial / sans-serif.
Composition: Retain the approved two-line title, purpose statement, and larger OPEN SCIENCE · OPEN SOURCE footer aligned to its gold rule.
Scientific motif: A deterministic double-well surface, drawn as a conceptual illustration without numerical claims, plus a version branch and a vector research-note folio.
Source: build_header.py regenerates ../ncc-header.svg with the Python standard library.
Output: 1200 × 500; preview at 900px and 360px. PNG renders are previews only; README embeds the SVG.
